The grammar — what every screen shares

05 · rules

Aside

  • Top: wordmark + screen chip
  • Middle: one context block — a statement + the recovery path, or the stepper on flows
  • Foot: location/identity left, audit note right
  • No feature lists, no marketing

Stage

  • Thin bar: screen position left, method/step right
  • Card centred, hard 1px border, 3px amber rule on top
  • Zero border-radius on every element, always
  • Mobile: aside collapses to a slim header strip

Card

  • Order: who badge → eyebrow → title → lead → banner → fields → primary
  • Footer strip for all secondary actions — nothing floats
  • Six segment OTP boxes; lockout is a bordered state card
  • Errors as banners above the form, not under fields
