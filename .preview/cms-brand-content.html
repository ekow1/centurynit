0 · What /cms becomes

One surface, seven tabs — the empty state dies

CmsManager.tsx today is 26 lines — "Content management is not yet available." The localStorage cmsOverlay the old manager wrote is dead (nothing writes it), yet useSiteContent() still polls it every 1.5 s. Both get deleted: the site fetches /content/* (edge-cached, revalidated on publish). /site's branding mock folds into Brand, its nav list into Navigation.

1 · Brand — the identity record every surface reads

This record is served as /brand.json + CSS vars into :root, server-rendered into index.html head, inlined into the email layout — edit once, every surface agrees.
