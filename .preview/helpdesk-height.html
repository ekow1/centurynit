Context rail .hd-rail — overflow-y:auto set but inside an unbounded parent it never actually scrolled ✓ maintained right of the chat — scrolls internally once the split is bounded; collapses via the existing "Details" toggle
Hub window border:1px + 0 12px 48px soft shadow · 430×620 ✓ border:1.5px + 5px 5px 0 hard shadow · 370×600 (portal size, expands to 800)
Hub header dot + "OPS CHAT" + rounded presence <select> ✓ avatar square (initials, presence-colored outline) + name + mono sub ● ONLINE · ROLE · BRANCH + —/⤢/✕; presence select moves to the strip
Channel tabs sans 12px, 2px underline, 4px dot badge ✓ mono 0.56rem uppercase, inset 0 -2.5px underline, red count chips (3, not a dot)
Context strip ✗ none ✓ muted mono band under tabs — directory context, presence select, or the open thread's "replies go to the portal / open in helpdesk →" link
Directory rows plain name + snippet + time ✓ avatar square (amber for groups, purple accent variant) + band labels (WAITING ON YOU / RECENT / ONLINE NOW) + red unread chips — portal row grammar
FAB + peek 0 8px 30px soft shadow, badge, no preview ✓ 3px 3px 0 hard shadow, badge, amber pulse on inbound, dismissible peek card of the latest message
