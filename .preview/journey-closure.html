Complete where you stop — continue by request, and the stage asks its own questions

One terminal state. When the stage the applicant reached is done — the plan's exit, or the point they chose to stop — the handler marks the journey complete. Picking up the next stage is a request the client sends; ops approves, the plan extends — and the new stage opens with its own intake: the questions and documents it needs that were never asked at consultation, minus whatever is already on file.

Intake isn't a payment gate — the file opens on the invoice. It's the officer's working checklist: the stage can be paid and waiting on you, and the chapter says so plainly.
  • Each stage carries an intake pack: Visa → the visa-history questions + its document set; Departure → the arrival questions (city, airport, housing, pickup, dependants) + its set. The same packs the assessment shows an entrant — reused, not re-authored.
  • Documents already verified in the vault are never re-asked — the checklist is the set minus what's on file, so a continuer's intake is short, not a second assessment.
