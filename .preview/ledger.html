What changed

Split by truth, not by date — settled payments sit above a ruled divider; scheduled charges below it, muted. Running balance — the balanceAfterCents the API already sends, so "Admissions GH₵2 paid → GH₵1 left" explains itself instead of looking like a double charge. Declined rows tell the story — the failure reason renders (failureReason was already on the row) with the retry date. Channels humanised — paystack-mobile_money → MoMo, card → Card. Reference + receipt move into the entry sub-line where they belong. A footer states the position — paid so far · still to come · what's due next.
