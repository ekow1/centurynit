C · Same shell, ended copy

It reuses the MeetingWindowModal shell — same scrim, same black-bordered card, same footer row — so the two states read as one product. The struck-through clock is the one visual difference: where the not-open modal shows when you can join, this one shows the end of the slot you missed.

  • Machine-readable: the 409 body gains startsAt/endsAt/timezone/reference — the same fields MEETING_NOT_OPEN already sends — so the modal names the slot in the booking's timezone instead of a frozen sentence.
  • The CTA differs by side: portal gets Reschedule → (into the existing move flow on Appointments). Ops gets dismiss-only — they manage the slot from the case, not from a popup.
  • Zero per-surface wiring where the hook is used: it renders inside useJoinMeeting's overlay, next to the not-open modal and the call UI.
  • No window change: the join window itself (staff −30 / client −15, +2h after the end) stays exactly as the server enforces it — this is only a better rendering of the same 409.
