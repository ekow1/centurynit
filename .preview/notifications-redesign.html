The current dropdown is a flat 20-item list with an All/Unread toggle and a dead "Enable alerts" button. This is the redesign: grouped by day, filterable by what it's about, an action label per item, mark-read without navigating, and an honest push-alerts row at the foot. Click things — the filters, dots and ticks are live.

What changes vs today

  • Day groups. Today / Yesterday / Earlier — the flat scroll becomes a timeline.
  • Type filters. All · Unread · Money · Docs · Journey · Messages, with counts. Money matters get found in one tap instead of scrolling past stage chatter.
  • Action label. Each item says where it goes — "View invoice →", "Open case →" — instead of a bare click target.
  • Mark read on hover. A ✓ chip per item — read it without leaving the page. Today clicking always navigates away.
  • Unread = ink bar. Left-edge bar + weight, not a floating dot — same signal language as the case rail.
  • Relative time. "12m ago" / "Yesterday" instead of a raw timestamp.
  • Honest push row. The foot shows real state: off → "Turn on", on → "On for this browser". Today the button calls a stub and does literally nothing.
  • Bug fixed. The live panel sets margin: 0 after marginTop on the body and timestamp — so body, time and meta all crowd together. Visible once you look for it.
