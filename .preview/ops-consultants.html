WHAT CHANGES. (1) Officer cards → officer rows. The cards repeat a stage-strip legend on every card and sprawl across the grid; as rows, each officer is one line: load count in a bordered cell, name + role + branch, the strip inline (greyscale, early→late = light→dark), and the stalled count bold on the right. (2) A real detail. Clicking a card today only narrows the shared list — you still can't answer "what is Akosua carrying?" without scanning it. The record pane answers it directly: load breakdown, this week's working hours (the new staffWorkingHours API you added — who can actually take the next slot), their records with chapter + to-do counts, and pending handoffs. Message stays the primary action. (3) The stage bands demote to a view — "By stage" keeps the current banded layout for the manager's sweep, but it's a toggle, not the default stacked under the cards. "Unassigned" is a counted pill, not a separate queue panel. (4) Count band replaces the "Who carries what" header line: officers · open cases · consults · average load · stalled inverted.
