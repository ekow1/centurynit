Workspace — the filter wall, fixed

The problem: the worklist puts 14 controls between you and the first task — 6 queue chips + 3 time chips + search + Type + "Date/Time" + Branch + Delegate. Half the chips read 0, the time chips duplicate the section bands the list already renders, "No handler" duplicates the Unassigned stat in the NOW rail, the "Date/Time" select actually sorts (it's mislabeled), and overdue work renders below today's — the most stale item on the page sits second. This pass: one row of real cuts, sections ordered by urgency, and everything else behind one disclosure.
