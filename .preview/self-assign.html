What changes

Admin-tier roles can own casework, but the roster never lists them — the sheet only renders eligible consultants. The fix is one pinned row at the top of the handler list:

  • "You" row, pinned first — shows when the signed-in user is super_admin, manager, or sys admin (anyone with assign_work / own-stage rights). Amber You chip, presence dot, role + "take this case" hint.
  • Selectable like any row — picking it submits the current user's own opsUserId; coverage and referral still apply, so a super admin can take "rest of the case" end-to-end.
  • Respects the rules — hidden when the stage genuinely can't be theirs (no own:* capability), hidden when they're already the handler.
  • Roster unchanged below — consultants still sort by fit and load; the self row just sits above them.

Backend already accepts it — the assign endpoint only checks the target can own the stage, and the recent admin-capability change covers that. This is purely the UI surface.
