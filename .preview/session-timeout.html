How it works

  • Idle clock — mouse, keyboard, and scroll reset a 2-hour timer; API calls do too.
  • Warning at 5 minutes — the prompt opens with a live countdown and a draining meter.
  • Stay signed in — pings the session endpoint (extends the cookie) and resets the clock.
  • Sign out / countdown zero — clears the session and lands on /login?reason=idle, which shows the "session ended" notice.
  • Background tabs — the timer is wall-clock based, so a hidden tab still expires on time.
  • Modal vs banner — pick A (can't miss it, forces a choice) or B (keeps working, pinned strip).
